# OpenCode Agents 2.0.0-dev.0 — prerelease draft

This is a development prerelease for testing the v2 package and Codex marketplace installation. It is not an execution-certified release. The source compatibility manifest has `execution_supported: false`; ordinary `opencode_start_task` calls remain gated. A private exact-workspace opt-in is available for authorized development testing in trusted workspaces.

## Included

- A bundled Node 24 MCP runtime, persistent supervisor, ten task tools, and bounded worker profiles.
- Durable admission, exact session and message reconciliation, follow-ups, cancellation, permission replies, immutable artifacts, and parent-owned reviews.
- A v2-only skill and evaluation harness. The Python job launcher, legacy import commands, and comparison runner are retired.
- A deterministic plugin ZIP, per-file SHA-256 manifest, and checksum sidecar.

## Validation so far

On macOS arm64 with Node 24.19.0, 87 runtime tests, nine packaging tests, and five evaluation harness tests pass. The 72-file read-only bundle smoke discovered ten MCP tools. An isolated Codex CLI 0.162.0 local marketplace install resolved the bundled MCP working directory and ran the diagnostic command. Selected authorized OpenCode 1.18.35 live cases passed; the complete release suite has not.

## Known limits

- OpenCode 1.18.35 can load a project plugin introduced after the toolkit's launch inspection. This plugin control race is an accepted development FIXME; use only trusted workspaces under the private opt-in.
- Attached backend dispatch and native questions remain disabled.
- Some permission and restart live cases remain unresolved. The twelve v2 scenario runs, performance targets, one-hour soak, Linux/WSL2 checks, and Git-backed marketplace install are pending.
- Existing imported database bytes are preserved, but v2 has no legacy import, replay, or continuation API.

See [v2 implementation status](../v2-implementation.md) for evidence and the remaining release gates. OpenCode, a supported Node 24.x runtime, and a configured provider/model are installed separately.

After the `v2.0.0-dev.0` tag is published, the repository marketplace can be installed with:

```bash
codex plugin marketplace add mike-holcomb/opencode-worker-plugin --ref v2.0.0-dev.0
codex plugin add opencode-agents@opencode-worker-plugin
```
