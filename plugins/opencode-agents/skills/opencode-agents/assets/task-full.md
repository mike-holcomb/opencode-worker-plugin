# Full v2 task packet

Use `tier: "full"` for a bounded task with substantial ambiguity or coverage. It still needs independence from other active work. Fill all required typed packet fields described in [standard](task-standard.md).

State objective-level failure conditions and exclusions. Separate original authoritative sources from generated interpretations and history; for blind review, omit prior verdicts. Carry verified facts and rejected assumptions in `context`. Identify base revision, relevant uncommitted state, predecessor artifacts, read dependencies, downstream interfaces, shared services, and freshness checks. Define exhaustive versus sampled coverage and contrary evidence before dispatch.

Use exact allowed writes and stable criterion IDs. Put staged checks, negative cases, and evidence requirements in `checks` and `acceptance_criteria`. Stop dependent work on missing input, stale interfaces, conflicting policy, repeated failed correction, or needed broader authority. Require a concise report with coverage, gaps, contradictions, uncertainty, failed or omitted checks, evidence pointers, and next action. Only the parent records acceptance.
